# Voces — Portal de comentarios

Aplicación grupal desarrollada con HTML, CSS, JavaScript, Bootstrap 5 y PHP 8. Permite recibir, almacenar y publicar comentarios mediante un archivo JSON protegido con bloqueo de escritura.

## Ejecutar localmente

```bash
php -S localhost:8000
```

Abrir `http://localhost:8000`.

## Publicación

El repositorio incluye configuración para CodeSandbox y Replit. En CodeSandbox, la tarea `Servidor PHP` inicia automáticamente el proyecto en el puerto 8000. En Replit se utiliza el puerto 3000.

Cuando el enlace remoto esté publicado, Bryant y Stanley deben entrar personalmente y dejar un comentario. La entrega debe incluir el enlace remoto y los nombres de ambos participantes.
